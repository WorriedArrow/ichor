# Linux ABI coverage (x86-64)

Generated by `cargo xtask linux-abi-table` from the syscall table in
`kernel/ichor/src/linuxabi.rs`; `cargo xtask lint` fails if this file is
stale. Do not edit by hand.

86 implemented, 32 partial, 0 stubbed. Every other syscall returns
`-ENOSYS`; which ones to add next is driven by tracing what real images
(busybox, then Alpine and Debian userlands) call.
